## 7. Product follow-ups (report, don't build)

1. **Trial mechanics**: the no-card trial excludes the roster, so an agent cannot try Agent Pro at all before paying. Either add `client_buy_box` to the evaluation entitlements or start a separate Agent Pro trial on first client creation.
2. **12 Buy Boxes per account** vs "up to 100 clients": raise `MAX_BUY_BOXES` for `agent_pro` or the promise "a Buy Box per client" is capped at 12.
3. **Multi-client screening**: `agent_client_matching` is built and flagged off; releasing it makes "which clients does this fit" real.
4. Onboarding role question (agent vs investor); `?plan=agent-pro` could at least persist the intent.
5. Portal copy in the app describes an unshipped feature (section 6).
6. Agent quotes via the `/reviews` process (first name, role, market).
7. Badge-position test on pricing once PostHog actually fires in production.
8. Monthly Agent Pro already exists ($59.99) — the brief's "annual-only" premise is wrong; nothing to build.
