# TrueCap — paste-ready ad copy

One Responsive Search Ad per ad group. Each ad below has:

- **15 headlines** (Google rotates and tests — give it as many as
  possible so it can find the winning combinations)
- **4 descriptions** (Google picks 2 to show per impression)
- **Display path** (the after-the-domain text in the ad URL)
- **Final URL** (the landing page)

Character limits (Google enforces these — don't exceed):
- Headlines: **30 chars** each
- Descriptions: **90 chars** each
- Display path: **15 chars** per segment

I've verified every line fits. Lines marked `★` are the strongest —
"pin" those to Position 1 in Google Ads so they always show first.

2, or 3. **Don't over-pin** (kills A/B testing), but pin strategically:
